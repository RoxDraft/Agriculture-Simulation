จำลองและออกแบบพื้นที่เกษตรSimulating and designing farmland

A set of pages for designing farmland from the national scale down to the river basin, the plot and the plant root. They explain plant structure and how farming relates to local people and the environment. Every page is plain HTML: open it directly or run it on GitHub Pages.

ชุดหน้าเว็บสำหรับออกแบบพื้นที่เกษตรตั้งแต่ระดับประเทศ ลงไปถึงลุ่มน้ำ แปลง และรากพืช อธิบายโครงสร้างของพืช ความสัมพันธ์กับคนในพื้นที่ และสิ่งแวดล้อม ทุกหน้าเป็นไฟล์ HTML ธรรมดา เปิดได้ทันทีหรือรันบน GitHub Pages
