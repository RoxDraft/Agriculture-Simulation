## เปิดบนเครื่อง

ดับเบิลคลิก `index.html` ได้เลย หรือรันเซิร์ฟเวอร์เล็กๆ:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## เผยแพร่ด้วย GitHub Pages

1. push ไฟล์ทั้งหมดขึ้น branch `main`
2. ไปที่ **Settings → Pages** ของ repo
3. ที่ **Build and deployment** เลือก Source เป็น **Deploy from a branch** แล้วเลือก `main` และโฟลเดอร์ `/ (root)`
4. รอราว 1 นาที หน้าเว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

## โครงสร้างไฟล์

```
index.html, thailand.html, nan-basin.html, soil.html
assets/
  site.css            สไตล์ร่วมของหน้าแรกและแผนที่ภูมิภาค
  thailand-data.js    พิกัดแม่น้ำ อ่าง เมือง ถนน ราง สายส่ง และข้อมูลภูมิภาค
  thailand.js         วาดแผนที่ ความสูง และตัวคำนวณ
  soil-lab.css/.js    ส่วนโต้ตอบหัวข้อ 10–13 ของหน้าดิน
parts/soil-new.html   ต้นฉบับ HTML ของหัวข้อ 10–13 (รวมอยู่ใน soil.html แล้ว)
```

ไลบรารีภายนอก: Google Fonts และ three.js r128 จาก cdnjs (เฉพาะหน้าลุ่มน้ำน่าน)

## ข้อจำกัด

- แผนที่เป็นแผนภาพเชิงอธิบาย เส้นเขตและความสูงเป็นค่าประมาณจากแบบจำลองแนวเทือกเขา ไม่ใช่ DEM จริง ถ้าจะออกแบบระบบส่งน้ำจริงควรใช้ DEM ของ GISTDA หรือ SRTM
- ตัวเลขที่ติดป้าย "อนุมาน" เป็นค่าประมาณเพื่อการออกแบบ ตัวเลขที่ใช้ตัดสินใจลงทุนควรตรวจกับหน่วยงานในพื้นที่
- ในหน้าดิน แหล่งที่มา 1–23 ตรวจกับต้นฉบับแล้วเมื่อ 23 ต.ค. 2026 ส่วน 24–26 ยังไม่ได้ตรวจ
